# Taller Django React

Plantilla base del taller. Backend Django + DRF, Frontend React (Vite).
El día 1 de la sesión haremos estos pasos en vivo juntos.

## Backend

```bash
# Opción A (directo, sin activar venv)
Backend\venv\Scripts\python manage.py runserver

# Opción B (activar venv primero)
cd Backend
venv\Scripts\activate
python manage.py runserver
```

Abre <http://localhost:8000>.

## Frontend

```bash
cd Frontend
npm run dev
```

Abre <http://localhost:5173>.
