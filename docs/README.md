# Guías del taller

Empieza por la guía de inicio. Después sigue los días en orden.

1. [Inicio rápido](01-inicio-rapido.md): instalar y arrancar el proyecto.
2. [Arquitectura](02-arquitectura.md): cómo React, Django y PostgreSQL se
   comunican.
3. [Día 1: El Velocista](03-dia1-el-velocista.md): misiones 1 a 5.
4. [Día 2: El Portero](04-dia2-el-portero.md): misiones 6 a 10.
5. [Día 3: Pentatlón Big Data](05-dia3-pentatlon-big-data.md): misiones 11 a 15.
6. [Datos de prueba](06-dataset-y-datos-masivos.md): generar contratos para
   practicar.
7. [Solución de problemas](07-solucion-de-problemas.md): qué revisar cuando
   algo no funciona.

## Si aparece un término nuevo

Cada guía incluye enlaces a la documentación oficial. Busca el término que no
entiendas, lee primero la explicación de esta guía y usa el enlace oficial para
ver más ejemplos.

## Antes de hacer un reto

- Revisa el archivo y el reto que indica la guía del día.
- No cambies `EstadoJardinView`: el panel la usa para comprobar el taller.
- No pongas claves en el código ni subas `Backend/.env` al repositorio.
- Los Minis 6, 7, 10 y 12 se aprueban cuando el panel comprueba el componente,
  el contador, el listado de la API o los datos de la gráfica.
