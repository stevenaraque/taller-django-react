Antes de empezar · actualiza el proyecto

Abre Git Bash en la carpeta raíz del proyecto y ejecuta estos comandos, en orden:

git stash push -m "guardar trabajo anterior del Mini 6" -- Frontend/src/features/misiones/dia2/Camaleon.jsx
git pull origin main

Si Git dice que no hay cambios para guardar, continúa con el segundo comando. No ejecutes git stash pop: restauraría la tarea anterior.

2 Construye 15 min

Trabaja en el archivo del componente:

Frontend/src/features/misiones/dia2/Camaleon.jsx
  1. Crea el componente EtiquetaSecop para mostrar SECOP II en un <span>.
  2. Haz que Camaleon use <EtiquetaSecop /> dentro de una sección.

Por ahora: no necesitas props, estado ni peticiones a la API. No cambies Mini6_Camaleon.jsx.

3 Ejecuta y comprueba 5 min
