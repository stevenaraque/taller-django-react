1. Qué es el stack de Django

El stack de Django de este proyecto tiene cuatro piezas que trabajan juntas:

  • Django 6.1: el framework web en Python. Maneja las rutas, las vistas, el ORM y el Admin.
  • Django REST Framework (DRF) 3.18: extiende Django para construir APIs que responden JSON. Aporta serializers, ViewSets y routers.
  • PostgreSQL 18: la base de datos real donde se guardan los contratos. Prohibido usar SQLite en el taller.
  • python-dotenv: lee Backend/.env y entrega las credenciales a Django sin escribirlas en el código.

Guion (di esto palabra por palabra)

«Django es el framework web en Python. No es solo una librería: es un conjunto de herramientas que ya resuelve lo aburrido: rutas, base de datos, seguridad, administración.»
«Django REST Framework es un agregado que convierte Django en una fábrica de APIs. Sin DRF, tendríamos que escribir a mano la conversión a JSON y la validación.»
«PostgreSQL es la base de datos real. No usamos SQLite porque el taller quiere que aprendan con el motor que usarán en producción.»
«python-dotenv lee el archivo .env y le entrega las credenciales a Django. Las credenciales nunca se escriben en el código.»
Django sigue el patrón MVT (Modelo-Vista-Template). En una API REST, el Template se reemplaza por el JSON que responde la vista.
